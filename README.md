## Description

This assignment focuses on JavaScript fundamentals, DOM manipulation, and event handling. It includes nine tasks demonstrating how JavaScript can make web pages interactive and dynamic.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Tasks

### Task 0 - First Script
- Display student name and group using `console.log()`.
- Show an alert message using `alert()`.

### Task 1 - Variables & Operators
- Declare string, number, and boolean variables.
- Perform arithmetic operations.
- Concatenate strings and display results in the console.

### Task 2 - Changing Content
- Create a paragraph and a button.
- Change paragraph text using JavaScript.

### Task 3 - Changing Styles
- Change the background color of an HTML element.
- Change the font size using JavaScript.

### Task 4 - Creating & Removing Elements
- Add new list items dynamically.
- Remove the last item from the list.

### Task 5 - Mouse Events
- Change the background color on mouseover.
- Restore the original color on mouseout.

### Task 6 - Keyboard Events
- Create a text input field.
- Display typed text in real time using the keyup event.

### Task 7 - Calculator
- Perform addition, subtraction, multiplication, and division.
- Display calculation results.
- Handle division by zero.

### Task 8 - Interactive To-Do List
- Add tasks with a title and description.
- Display tasks dynamically.
- Mark tasks as completed.
- Delete tasks.
- Store tasks temporarily in a JavaScript array.

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Use the navigation bar to switch between tasks.
5. Interact with the buttons, input fields, and other elements.
6. Open the browser developer console to view the output of Tasks 0 and 1.
